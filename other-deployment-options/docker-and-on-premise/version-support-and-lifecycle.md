# Version Support and Lifecycle

{% hint style="info" %}
### Support window: 6 months

DecisionRules supports each Docker and on-premises release for **6 months** after its release date.
{% endhint %}

Support includes bug fixes and security updates. Upgrade to a supported release before the support window ends.

### Lifecycle policy

The six-month period starts on the release date. A release becomes unsupported when it is older than six months.

We recommend upgrading to the latest available release. This gives you the newest fixes, security updates, and features.

{% hint style="warning" %}
Unsupported releases do not receive bug fixes or security updates. Support may require upgrading before investigation begins.
{% endhint %}
